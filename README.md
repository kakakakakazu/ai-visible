# AIから見えていますか

ChatGPT・Claude・Perplexity・Gemini などのAIから、あなたのWebサイトの中身が読めているかを100点満点で診断し、修正ファイルを自動生成する無料ツールです。

**外部APIもサーバーも使いません。** 判定はすべて閲覧者のブラウザ内で完結し、入力したデータはどこにも送信されません。

## なぜ必要か

検索した人の **68%** は、もうサイトを訪れません（ゼロクリック検索、2026年。10年前は45%、2024年は60%）。AIが要約して答えて終わりです。10〜20代の **47.4%** は最初からAIに質問します。AI Overviews が表示されたクエリでは、自然検索のクリックが **約38%** 減少しています。

このとき流入が減る原因は、多くの場合コンテンツの質ではありません。**AIがサイトの中身に到達できていない**ことです。そして当事者はその可能性に気づいていません。

## 診断項目と配点

| 項目 | 配点 | 内容 |
|---|---|---|
| AIクローラーの許可 | 28 | robots.txt による13種類のAIクローラー遮断を検出（RFC 9309 準拠） |
| 本文がHTMLに存在するか | 20 | JavaScript依存でAIに空ページと見える状態を検出 |
| 構造化データ | 12 | JSON-LD の有無と妥当性 |
| 出典・一次情報リンク | 12 | 学術・公的機関・標準化団体へのリンク |
| 統計・数値 | 11 | 本文中の数値表現の量 |
| タイトルと説明 | 7 | title / meta description |
| 要約の起点になる見出し | 4 | 「まとめ」「〜とは」「よくある質問」など |
| 更新日時 | 3 | time要素 / dateModified |
| HTMLの意味構造 | 2 | main / article / section の使用 |
| llms.txt | 1 | 設置の有無 |

### 配点の根拠

出典12点・統計11点という重みは、**KDD 2024 で発表された査読論文「GEO: Generative Engine Optimization」**（プリンストン大学ほか）の測定結果に基づいています。出典の明記で生成エンジンでの可視性が **約40%**、統計の追加で **約37%**、引用の追加で **約22%** 向上したと報告されています。

llms.txt を1点に留めているのは、AIボットの訪問のうち llms.txt が取得されるのは **0.1%程度** という実測があり、主要クローラーが llms.txt を無視して直接HTMLを読む傾向があるためです。

h1 の有無は減点対象にしていません。実在サイト6件を調べたところ5件が h1 を持っておらず、減点の根拠が薄いと判断しました（情報としては表示します）。

## 使い方

3通りあります。

1. **HTMLファイルを渡す** — ブラウザで自分のサイトを開き、ページのソースとして保存したファイルをドロップ
2. **ソースを貼る** — `⌘U` / `Ctrl+U` でソースを表示し、全選択してコピー、貼り付け
3. **ブックマークレット**（推奨） — ページ上のボタンをブックマークバーにドラッグ。自分のサイトを開いた状態でクリックすると、HTML・robots.txt・llms.txt・sitemap.xml をまとめて取得します

3が最も精度が高くなります（robots.txt を含めて判定できるため）。

## 生成される修正ファイル

- **llms.txt** — サイト名・説明・主要な見出しから自動生成
- **robots.txt 追記案** — 遮断されているAIクローラーの許可設定
- **JSON-LD** — Organization 型の構造化データ

## 公開している実測データ

日本の主要サイト24件を**毎週定点観測**し、集計統計を公開しています → [data.html](https://kakakakakazu.github.io/ai-visible/data.html)

2026-08-09 時点で、何らかのAIクローラーを遮断しているサイトは **16.7%**、AI可読性スコアの中央値は **76点**（最低19・最高91）、**llms.txt の設置率は 0%** でした。

**個別のサイト名・URL・個別スコアは公開しません。**順位をつけることが目的ではないためです。
巡回は robots.txt を尊重し、全クローラーを拒否しているサイトについては本文を取得せず、遮断状況のみを集計しています（「AIを拒否しているサイトほど測定から漏れる」という選択バイアスを避けるため）。

## 技術

- 静的ファイルのみ。ブラウザ側の依存ライブラリなし（`index.html` + `engine.js`）
- **判定ロジック（`engine.js`）は診断ツールと定点観測スクリプトが共有**。同じ入力には必ず同じ点数が出る
- 外部APIを1回も呼ばない。判定はすべて決定的なルールによる静的解析
- 定点観測は GitHub Actions（public リポジトリは無料）。実行時にLLM APIを一切呼ばない
- robots.txt の解析は RFC 9309 準拠（User-agent 専用ブロックがワイルドカードに優先する最長一致）

## 検証

実在サイト6件で動作を確認し、診断出力（JSON-LD数・h1数・本文字数）をDOMで直接数えた実測値と全件照合しています。
